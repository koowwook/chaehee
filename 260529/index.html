가계부 앱 네이밍 후보 2차 검토

이번 후보는 “혼자 쓰는 가계부”보다 사람과 AI가 옆에서 같이 봐주는 돈 습관이라는 방향을 중심으로 정리했습니다.

이번 검토의 기준

앱의 핵심 감정은 단순히 지출을 기록하는 것이 아니라, 비슷한 사람들의 흐름을 보며 내 기준을 찾고 AI가 옆에서 해석을 도와주는 경험에 있습니다.

혼자 쓰는 느낌보다 함께 관리하는 느낌
다른 사람과 AI가 옆에서 도와주는 느낌
돈, 소비, 가계부를 직접 말하지 않아도 연결되는 이름
무니카드, 커뮤니티, 리포트로 확장 가능한 이름
아래 구분은 1차 상표 검색 결과와 내부 선호도를 합쳐 정리한 것입니다. 최종 확정 전에는 상품류와 유사 상표를 다시 확인하는 것이 좋습니다.

상표 검토 상태별 정리

이름감과 앱 방향성은 좋지만, 최종 사용 전에는 유사 상표와 실제 서비스명 혼동 가능성을 한 번 더 확인할 후보입니다.

애매 가능성 낮은 후보

현재 없음

이번 2차 후보군에서는 가능성이 낮아 보이는 후보는 따로 두지 않았습니다.

가능 현재 남길 수 있는 후보

오르달 가치봄 가치잇 가치온 곁온

현재 기준으로는 계속 검토 가능한 후보입니다. 다만 가치온은 애매 후보에도 함께 올라와 있어, 최종 확정 전 재확인이 필요합니다.

가치봄 가능 가능 같이 봄, 가치를 봄. 따뜻하고 다정함 다른 사람과 AI가 옆에서 봐주는 느낌과 잘 맞음 서비스의 핵심 경험을 부드럽게 담음 봄 계열이 감성적이라 금융앱의 단단함은 조금 약할 수 있음

곁온 가능 가능 곁에 켜져 있는 느낌. 조용하고 따뜻함 AI도 사람도 옆에서 함께 도와주는 경험과 가장 잘 맞음 직접적이지 않으면서 브랜드 감성이 좋음 돈관리 앱이라는 설명력은 약해 메인 카피가 중요함

이름별 상세 검토

우리가치 애매 후보

“우리 같이”와 “우리 가치”가 동시에 읽히는 후보입니다. 커뮤니티형 가계부라는 방향은 가장 쉽게 전달되지만, 이름 자체가 조금 캠페인 문구처럼 느껴질 수 있습니다.

추천 카피: 혼자 보던 가계부를 함께 보는 습관으로.

채온 애매 후보

기록이 채워지고, 목표가 채워지고, 돈 습관이 따뜻하게 쌓이는 느낌입니다. 여성 타깃에게 부드럽게 다가갈 수 있고 캐릭터화도 무난합니다.

추천 카피: 내 돈 습관이 차곡차곡 채워지는 곳.

차온 애매 후보

“차오르다”가 먼저 떠올라 월간 기록, 저축, 달성 카드와 잘 맞습니다. 돈을 직접 말하지 않아도 성장감이 살아 있는 점이 장점입니다.

추천 카피: 한 달의 기록이 차오르면, 내 기준도 보입니다.

달온 애매 후보

한 달, 달, 보름달, 동전 이미지가 자연스럽게 연결됩니다. 무니카드처럼 성취를 모으는 기능과 특히 잘 맞는 후보입니다.

추천 카피: 한 달의 돈 습관을 켜다.

가치온 애매 후보재확인

같이, 가치, on이 모두 읽혀 앱의 철학을 넓게 담을 수 있습니다. 사람과 AI가 함께 내 돈의 기준을 찾아준다는 방향에는 가장 잘 맞는 편입니다.

추천 카피: 돈 관리, 이제 같이 켜요.

오르달 가능 후보

달이 오르고, 내 돈 습관도 오른다는 이미지입니다. 독특한 이름이라 기억성은 있지만, 처음 들었을 때 의미 해석이 조금 필요합니다.

추천 카피: 기록할수록 차오르는 한 달.

가치봄 가능 후보

함께 본다는 뜻과 가치를 본다는 뜻이 겹칩니다. 커뮤니티와 AI 분석이 모두 “봐준다”는 행동으로 묶여 자연스럽습니다.

추천 카피: 비슷한 사람들과 함께 내 기준을 봅니다.

가치잇 가능 후보

“가치 있다”와 “잇다”가 동시에 읽히는 후보입니다. 사람과 사람, 기록과 해석, AI와 사용자를 연결하는 느낌을 줄 수 있습니다.

추천 카피: 내 돈의 기준을 잇다.

곁온 가능 후보

AI도 사람도 내 곁에서 조용히 도와주는 느낌입니다. 가장 덜 직접적이지만, 브랜드로 만들었을 때 감정의 여백이 좋습니다.

추천 카피: 혼자 적던 돈 습관에 곁을 켜다.

아내 피드백 반영

대화에서 확인된 방향

  • 온 계열은 선호도가 낮음. “온”이 들어간 이름은 옛스럽게 느껴진다는 의견.
  • 이름에 앱 정체성을 모두 담을 필요는 없음. 확장 가능성을 생각하면 입에 붙고 오래 기억되는 이름이 더 중요할 수 있음.
  • 계속 새 이름을 만드는 것보다 기존 후보 중 실제 가능한 이름을 좁히는 단계가 필요함.
  • 아내가 다시 언급한 핵심 후보: 모이딧, 채온, 쿼티, 노타.
  • 오플은 아내 선호가 있는 후보. 다만 보스의 1차 상표 확인 기준으로는 충돌 가능성이 높아 전문가 재확인이 필요함.

아내 추가 검토 의견

추가 의견의 핵심

이번 대화에서 새로 확인된 중요한 관점은 “예쁜 이름”보다 기억에 오래 남고 입에 붙는 이름일 수 있다는 점입니다. 이름에 가계부의 정체성을 모두 담기보다, 나중에 브랜드가 커졌을 때 확장 가능한 고유명사형 이름도 함께 검토할 필요가 있습니다.

상표권은 보스가 1차로 확인한 내용을 함께 반영했습니다. 아래 평가는 최종 법률 판단이 아니라, 전문가에게 물어보기 전 후보를 좁히기 위한 임시 메모입니다.

이름 대화에서 나온 맥락 브랜드로 보이는 가능성 검토할 점
오플 재확인 아내가 “좋다”고 다시 언급한 후보 짧고 앱 이름처럼 들림. 의미를 많이 설명하지 않아도 기억에 남는 쪽 보스 1차 확인 기준으로는 상표 충돌 가능성이 높아 보임. 아내 선호가 있으므로 전문가에게 최종 확인할 후보
무늬 검토 무니와 가까운 어감으로 다시 떠올린 후보 패턴, 결, 흔적의 느낌이 있어 기록형 앱과 연결 가능 일반명사성이 강하고 기존 후보 무니와 혼동 가능성 확인 필요. 상표 가능성은 별도 확인 필요
도토리 재확인 풍요, 모으는 습성, 다람쥐 이미지에서 나온 후보 당근마켓처럼 직관적 고유명사로 밀면 기억성은 좋음 보스 1차 확인 기준으로는 싸이월드/네이트 쪽 기존 상표가 있어 사용 어려울 가능성이 높음
도시 검토 “도시 가계부”처럼 대놓고 기억에 남는 이름으로 제안 짧고 선명함. 세련된 도시 생활자의 돈관리 이미지 가능 가계부와 직접 연결은 약해 카피/디자인 방향이 중요. 상표 가능성은 별도 확인 필요
서울 검토 해외 확장 시 서울이라는 상징성을 고려한 후보 한국발 서비스, 글로벌 확장, 지역 브랜드 스토리를 만들기 좋음 지명 사용의 상표 가능성, 검색성, 금융앱 적합성 확인 필요. 대화 기준으로는 가능성 미확인
쿼티 검토 기록/매일의 의미를 가진 단어감으로 제안 짧고 독특함. 입력, 기록, 루틴의 느낌을 줄 수 있음 보스 의견상 가능할 것 같지만 의미 연결성은 약함. 상표 최종 확인 필요
노타 검토 기록의 의미를 가진 후보. “노타 서울/아메리카/재팬” 확장 상상 글로벌 브랜드처럼 확장하기 좋고, 기록 앱의 느낌도 있음 보스 의견상 가능할 것 같지만 기존 서비스/상표 유사 여부 최종 확인 필요
